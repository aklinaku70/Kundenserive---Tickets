# Kundenservice Pro — Trajnim & Simulim i Call Center-it

**Krijuar nga:** ArdianGraphics

Mjet trajnimi për shërbimin ndaj klientit në gjuhën gjermane (Sie-Form, Geschäftssprache, niveli B2/C1), i ndërtuar si dy faqe të thjeshta HTML.

## 🔗 Faqja live
👉 https://aklinaku70.github.io/Kundenserive---Tickets/kundenservice-pro.html

*(zëvendëso me linkun tënd real pasi të aktivizohet GitHub Pages)*

## 📄 Skedarët

| Skedari | Përshkrimi |
|---|---|
| `index.html` | Materiali i trajnimit — 10 raste tipike klientësh, me mesazhe në gjermanisht, fraza të gatshme formale dhe këshilla praktike. |
| `kundenservice-pro.html` | Konsola live e "Live Agent" — simulon tiketa reale (email, chat, telefon), me SLA, statuse, shënime interne, eskalim dhe KPI. |

## ▶️ Si përdoret
1. Hap `index.html` (ose linkun bazë të GitHub Pages).
2. Lexo 10 rastet dhe bankën e frazave.
3. Shtyp **"🚀 Përfundo Trajnimin — Dil Live Agent"** për të kaluar te konsola.
4. Puno me tiketat që mbërrijnë automatikisht — përgjigju në Sie-Form, respekto SLA-në, dhe eskalo kur kërkesa e klientit tejkalon politikën.

## 🛠️ Teknologjia
HTML5, Tailwind CSS (via CDN), JavaScript vanilla — pa asnjë dependencë ndërtimi (build step).

> Butoni i përkthimit automatik (🌐 Shqip) në konsolë funksionon vetëm brenda mjedisit claude.ai; kur faqja hapet nga GitHub Pages, ai shfaq një mesazh informativ në vend të thyerjes së faqes.
